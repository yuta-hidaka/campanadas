# campanadas

This app celebrates the new year with the Spanish tradition Las Campanadas.

## Native chime loop

`swift run CampanadasCoreCheck` runs the year-crossing and TEST state engine, the clock face, and the SwiftUI loop's cue wiring (executable checks; works with the macOS Command Line Tools toolchain).

`swift run Campanadas` opens the macOS slice: grape count, clock, and the TEST bell sequence through AVFoundation.

`swift test` is available when a full Xcode install provides the Testing module.
